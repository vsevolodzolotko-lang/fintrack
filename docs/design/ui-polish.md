# UI-полірування дашборда — Gold Money

Мета: підтягнути **реальну апку** (поточні скрини) до візуального рівня дизайн-мокапа
`Budget App.dc.html`. Логіка й дані НЕ змінюються — тільки стилі: типографіка, картки,
відступи, кольори, бари, донат, хедер, таб-бар. Джерело правди — сам мокап
(`Budget App.dc.html`, відкривається в браузері).

Стек: React + Vite, рукописний CSS з токенами в `:root`. Усі значення нижче — точні,
можна класти напряму.

---

## 0. Дизайн-токени (звірити з `:root`)

```
--bg:            #0f1117;   /* екран */
--bg-deep:       #05070c;   /* підкладка */
--card:          #1a1d27;   /* усі картки/секції */
--card-inset:    #1e222e;   /* інпути, вкладені плитки */
--gold:          #F5A623;   /* акцент, hero, CTA, FAB, active */
--gold-lt:       #ffbe4d;   /* партнер градієнта */
--green:         #4CAF50;   /* дохід/успіх */
--teal:          #4FC3C6;   /* ETF, "Відкласти" */
--red:           #EF5350;   /* витрати, попередження */
--coral:         #EF6C6C;   /* конверт близько ліміту */
--text:          #EDEFF5;   /* основний */
--text-muted:    #a4a9bd;   /* вторинний */
--text-dim:      #6c7185;   /* капшени, meta */
--tab-idle:      #5b6070;
--hairline:      rgba(255,255,255,.05);
--person-a:   #5B8DEF;
--person-b:    #E86BA5;
```

Радіуси: картки/секції **18px**, інпути/плитки **13px**, чипи/бари/аватари **999px**,
FAB **20px**. Відступ між секціями **26px**, між картками в секції **12px**,
горизонтальні поля екрана **20px**, нижній паддінг під таб-бар **100px**.

---

## 1. Типографіка (найбільший приріст «краси»)

Підключити **дві** родини (Google Fonts): `Manrope` (400–800) і `Space Grotesk` (500–700).

- **Усі грошові числа — Space Grotesk**, не Manrope. Це hero, суми конвертів,
  баланси рахунків, центр донату, суми в «Хто скільки», значення ETF/Цілей.
  Зараз у апці числа набрані тим самим жирним Manrope — через це виглядають грубо.
- **Hero:** Space Grotesk 700, `font-size:78px; line-height:1; letter-spacing:-.02em;`
  колір `--gold`, `text-shadow: 0 6px 40px rgba(245,166,35,.28)`.
- **Заголовки секцій:** Manrope 800, `17px`, `--text`. Праворуч — meta
  («цей цикл») Manrope 600, `12.5px`, `--text-dim`.
- **Kicker** (напр. «СПІЛЬНИЙ БЮДЖЕТ»): 700, `12px`, `letter-spacing:.12em`,
  `text-transform:uppercase`, `--text-dim`.
- Тіло: 13–15px / 600–700. Капшени під барами: 12px / 600.

---

## 2. Хедер (зараз лише «Gold Money»)

Замість самотнього логотипа — рядок:
- Зліва: kicker `СПІЛЬНИЙ БЮДЖЕТ` + під ним `Липень · цикл до 31-го`
  (Manrope 600, 15px, `--text-muted`).
- Справа: **сегментна пігулка-фільтр** `Разом · Партнер A · Партнер B`
  (контейнер `--card`, radius 999, padding 3–4px; активний сегмент — золото на
  `rgba(245,166,35,.18)`, неактивні — `--text-dim` на прозорому). Фільтр реально
  перераховує hero, конверти й донат по людині; попередження про перевитрату —
  лише в «Разом».

---

## 3. Картки — єдина система

Кожна картка/секція: `background:var(--card); border:1px solid var(--hairline);
border-radius:18px; padding:16px`. Прибрати різнобій радіусів/фонів, які є зараз.
Тіні для контенту не потрібні (площинні картки на темному).

---

## 4. Конверт «На життя» (зараз плаский бар)

- Рядок зверху: назва (700, 14.5px, `--text`) ⟷ `<spent> / <budget>`
  у Space Grotesk 14px; spent — `--text`, budget — `--text-muted`.
- **Трек:** `height:9px; background:rgba(255,255,255,.06); border-radius:999px`.
- **Заповнення:** `linear-gradient(90deg,#F5A623,#ffbe4d)`, `border-radius:999px`,
  `transition:width .4s`. Якщо ≥75% ліміту — градієнт коралевий
  `linear-gradient(90deg,#EF6C6C,#ff8f8f)`.
- Мітку «сьогодні» (вертикальна риска на треку) можна лишити — але тонку,
  `rgba(255,255,255,.35)`, поверх треку.
- Капшен: `Залишилось ₴… · N%`, 12px/600 `--text-dim`; при ≥75% — колір `--coral`,
  700, текст «майже вичерпано».

---

## 5. «Хто скільки»

- **Двоколірний бар часток** зверху: висота 10, radius 999, сегменти з gap 2px —
  Партнер A `--person-a`, Партнер B `--person-b`, нерозподілене `--text-dim`.
  (Коли все нерозподілено — один сірий сегмент, як зараз, це ок.)
- Рядки: **аватар 26px** (коло, фон = колір персони 18% прозорості, ініціал —
  світлий відтінок того ж кольору) + ім'я (700, 13.5px) ⟷ сума (Space Grotesk 14px)
  + частка `%` (`--text-dim`, 12px, ширина 40px, вирівняна праворуч).
- «Не розподілено»: бейдж `?` з `dashed` бордером `rgba(255,255,255,.16)`, `--text-dim`.

---

## 6. «Відкласти в ETF»

Повноширинна картка-рядок: назва (700, 14.5px, `--text`) ⟷ значення
(Space Grotesk 700, колір `--teal`) + шеврон `›` `--teal`. Легкий teal-акцент бордера
опційно (`rgba(79,195,198,.22)`).

---

## 7. «Цілі»

- Заголовок секції ⟷ сума справа (Space Grotesk 700, `--gold`).
- Чип «Нерозподілено: 0 грн» — `background:rgba(245,166,35,.1); color:--gold;
  border:1px solid rgba(245,166,35,.28); radius:999`.
- Ціль: назва + `X / Y грн` (Space Grotesk), під нею трек як у §4 (гейтем прогресу).
- Кнопка «+ Поповнити» — pill, `--card-inset` фон, `--text`.
- Інпути нової цілі: `background:var(--card-inset); border:1px solid rgba(255,255,255,.06);
  radius:13; color:--text; placeholder --text-dim`. Кнопка «+» — золота, radius 13.

---

## 8. «Рахунки»

Одна картка, рядки через дільник `1px var(--hairline)` з інсетом 16px:
- Ліворуч — плитка 40px, radius 11 (для «black UAH» — золотий градієнт
  `linear-gradient(135deg,#F5A623,#d98a10)`; для «white UAH» — `#05060a` з бордером).
- Назва (700, 14.5px) + підпис «Картка» (12px, `--text-dim`).
- Баланс праворуч — Space Grotesk 16px/700, `--text`.

---

## 8-bis. «Цілі» (на що збираємо — окрема біла картка Mono)

Секція-картка перед «Рахунками». Кошти цілей фізично лежать на білій картці Mono
(показати це підписом-міткою біля заголовка: маленький світлий прямокутник +
«біла картка»).

- Заголовок «Цілі» ⟷ мітка «біла картка» справа.
- **«Відкладено всього»** — сумарно по всіх цілях, Space Grotesk 22px/700 `--gold`.
- **Чип «Вільно ₴…»** — нерозподілений пул (кошти на картці, ще не прив'язані до цілі):
  `background:rgba(245,166,35,.10); border:1px solid rgba(245,166,35,.28); radius:999`,
  ховається коли пул = 0.
- **Ціль (рядок):** емодзі + назва зліва ⟷ `<saved> / <target>` (Space Grotesk,
  saved — `--text`, target — `--text-muted`). Під ним слім-трек h8 radius999
  (`rgba(255,255,255,.06)`) з градієнт-заповненням `#F5A623→#ffbe4d`
  (`transition:width .45s`). Досягнута ціль → зелений градієнт `#4CAF50→#7fe082`.
  Капшен: `N% · залишилось ₴X` (`--text-dim`); при досягненні — «Ціль досягнуто ✓»
  зеленим.
- **«Поповнити»** (pill справа під баром) — переказує суму з вільного пулу в ціль;
  гасне, коли пул порожній або ціль виконана.
- **Нова ціль:** інпути `--card-inset` (назва + сума) + золота кнопка «+», radius 12,
  над дільником `1px --hairline`.

---

## 9. Донат «Витрати за категоріями» (зараз надто важкий)

Замінити товсте суцільне кільце на компактне:
- Кільце **132px**, `conic-gradient` по сегментах категорій; всередині отвір
  `inset:17px` кольору `--card`.
- Центр: сума Space Grotesk 19px/700 `--text` + «за цикл» 10.5px `--text-dim`.
- Легенда праворуч: рядки з **квадратним дотом 9px radius 3** у кольорі сегмента +
  назва (`--text` приглушений) + сума (Space Grotesk 13px).
- Палітра сегментів: `#F5A623, #4FC3C6, #7C83FF, #EF6C6C, #4b5163`.

---

## 10. Таб-бар + FAB

- Бар: висота 88px (з safe-area), фон-градієнт до `--bg`, легкий blur.
  Активний пункт — `--gold`, неактивні — `--tab-idle`; лейбли 10.5px/700.
- **FAB:** не плаский квадрат із різким світінням, а
  `background:linear-gradient(135deg,#F5A623,#e08c0f); border-radius:20px;
  width/height:58px; box-shadow:0 10px 26px rgba(245,166,35,.4);` піднятий `-6px`.
  Іконка «+» stroke `#1a1200`, 2.6.

---

## Порядок робіт (пріоритет за впливом)

1. Типографіка (§1) — Space Grotesk на всі числа + hero. Найбільший ефект.
2. Єдина карткова система + відступи (§3, §0).
3. Конверт-бар і «Хто скільки» бари (§4, §5).
4. Донат (§9) і FAB/таб-бар (§10).
5. Хедер із фільтром (§2), Цілі/Рахунки (§7, §8).

Іконки — `lucide-react`, stroke 1.8–2, round caps. Донат/чарти — Recharts.
