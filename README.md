# FinTrack · Gold Money

Спільний бюджет на двох поверх Monobank. Self-hosted PWA: транзакції прилітають вебхуком,
категоризуються жестом на радіальному колесі, дохід ділиться по конвертах, а денний ліміт
сам вирівнюється до кінця циклу. Плюс цілі, інвестиційний план і портфель (ОВДП, REIT, крипта
через Binance).

Це особистий проєкт під один домогосподарський сценарій, а не продукт. Код відкритий, щоб
можна було подивитись, як це зроблено, і підняти собі копію.

## Що вміє

- **Monobank**: вебхук на нові операції, пул балансів рахунків і банок кожні 5 хвилин,
  доімпорт виписки за останні 31 день, звірка hold-операцій після розблокування.
- **Категоризація жестом**: 7-секторне радіальне колесо з другим рівнем листів. Напрямок
  вибирає сектор, відстань відкриває фан. Порядок секторів зафіксований, бо весь сенс у
  мʼязовій памʼяті.
- **Цикли й конверти**: цикл стартує від основного надходження, дохід ділиться за
  відсотками на побут, інвестиції та цілі. Бюджети рахуються на льоту, нічого не дрейфує.
- **Денний ліміт**: `(бюджет побуту − витрачено) / днів до кінця циклу`. Перевитратили
  сьогодні, завтра ліміт менший.
- **Двоє людей**: атрибуція витрат по токену або вручну, фільтр «Разом · A · B», історія
  по місяцях і категоріях із розбивкою, хто платив.
- **Інвестиції**: план на місяць із чеклістом, драбинка ОВДП з купонами, знімки вартості
  REIT, крипто-портфель з Binance (лише читання), єдина історія внесків на три інструменти.
- **PWA**: темна тема Gold Money, встановлюється на телефон, pull-to-refresh, свайпи.

## Стек

| Шар | Технології |
| --- | --- |
| Сервер | Node.js, Fastify 4, Prisma, PostgreSQL 16, node-cron |
| Веб | React 18, Vite, TanStack Query, React Router, Recharts, lucide-react, hand-written CSS |
| Деплой | Docker Compose, Caddy (внутрішній HTTP-роутер), Cloudflare Tunnel |

Гроші всюди `BigInt` у копійках, у JSON приходять рядком. Усі «денні» розрахунки в
київському часовому поясі. Токени Monobank зашифровані AES-256-GCM, ключ живе лише в `.env`.

## Локальний запуск

```bash
cp .env.example .env          # заповнити секрети (див. нижче)
npm install                   # обидва воркспейси
npm run db:generate           # prisma generate
docker compose up -d db       # лише Postgres, порт 5432 на loopback
npm run db:migrate            # схема
npm run db:seed               # базові категорії та MCC-правила
npm run dev                   # server :3000 + web :5173
```

Секрети:

```bash
openssl rand -hex 32          # SESSION_SECRET
openssl rand -hex 32          # TOKEN_ENC_KEY (рівно 32 байти в hex)
```

Перевірка коректності:

```bash
npm run test --workspace=server
npm run test --workspace=web
npm run typecheck --workspace=web
```

## Деплой

`docker compose up -d --build` піднімає `db → server → web → caddy → cloudflared`. TLS
термінується на межі Cloudflare, Caddy слухає plain HTTP усередині docker-мережі без
відкритих портів. У `.env` потрібні `CLOUDFLARE_TUNNEL_TOKEN` і `PUBLIC_BASE_URL`
(публічна адреса, на яку Monobank шле вебхуки). Тунель у Cloudflare Zero Trust вказує на
`http://caddy:80`.

`scripts/deploy.sh` робить push, бекап БД на сервері, pull, rebuild і health-check по SSH.
`scripts/rollback.sh` повертає на попередній коміт і за потреби відновлює дамп. Обидва
беруть адресу з `FINTRACK_SSH`, каталог із `FINTRACK_DIR`.

## Підключення Monobank

1. Кожен із двох отримує персональний токен на https://api.monobank.ua/ зі свого логіну.
2. У застосунку: Налаштування → додати токен. Він шифрується й у відкритому вигляді не
   зберігається.
3. Сервер сам реєструє вебхук `PUBLIC_BASE_URL/mono/hook/<секрет>` і починає пул балансів.

## Підключення Binance

Ключ створюється в Binance → API Management лише з правом **Enable Reading**. Сервер
перевіряє права через `apiRestrictions` і відмовиться синхронізувати ключ із зайвими
дозволами. Ключі живуть у `.env`, у БД не потрапляють. Імпортуються P2P-покупки USDT за
UAH, конвертації та спот-угоди по парах із `BINANCE_SPOT_SYMBOLS`.

## Безпека

- Реєстрація закривається після двох користувачів.
- Логін і реєстрація обмежені 10 спробами на хвилину з однієї IP.
- Секрет вебхука криптовипадковий, 24 байти.
- Сесії в Postgres з TTL 30 днів, cookie `httpOnly`.
- База слухає лише loopback хоста; назовні виходить тільки Cloudflare Tunnel.

Якщо знайдете вразливість, напишіть в issues без деталей експлуатації, далі спишемося.
